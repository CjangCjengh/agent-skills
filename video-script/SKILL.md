# 视频文案

- 成稿要能直接朗读，像一个熟悉资料的人把事情讲清楚。默认采用理性、口语化、接地气的表达，不写成研究报告、宣传稿、播音稿或抒情散文；用户给出的文风示例和当前要求优先。

- 先判断观众熟悉什么、不熟悉什么。熟悉某种文化，不等于知道另一国的行业、某个小圈子的争议或十几年前的热门作品。用户在对话里已经讲过的背景，视频观众未必知道。

- 不反复解释观众已经懂的常识，也不省略理解本期内容必需的背景。例如受众知道什么是网文，就不必从网上读小说解释起；首次出现陌生平台时，仍需交代它在哪个国家、主要做什么。

- 用户给出的书单、事件和印象是调研线索，不是调研边界，也不是已经核实的事实。主动寻找会影响主线的大事件、遗漏的阶段和反例，不等用户逐个提醒。用户的随口概括不能直接写成当地通行的术语。

- 研究一个行业，要查它如何起步，作品通过什么渠道流通，平台或出版社怎样经营，作者与受众如何迁移，以及关键变动的前因后果。不要只搜索几部作品，再把搜索结果按年份排列。

- 涉及外国材料，尽量用当地语言查公告、原始帖子、作者或编辑访谈、出版目录和作品正文。百科和二手文章可以帮助找线索；转载同一条消息的多个网站不算独立证据。查不到的细节不能靠听起来合理的故事补齐。

- 选材前明确本期讨论的范围，核实具体作品是否符合。出版物的实际形态、平台标签和营销名称可能不同。必要的前史可以讲，但要交代它属于什么，不能因为相邻题材的材料多，就混进同一类别凑篇幅；也别把本期采用的口径说成唯一公认的定义。

- 同一作品的网络连载、改写版、纸书、电子分卷、译本和改编作品分别核对。原作完结、某语言的连载停更、译本未译完可以同时发生。不要用一个版本的进度、封面、插画或结局替代另一个版本。

- “第一”“唯一”“全是”“没有”“普遍”“大部分”等说法需要相应范围的证据。只找到一个例子，不能说只有一个；某个榜单的前几名，也不能代表整个市场。没有足够材料时，把实际能确认的事情说清即可。

- 数据比较要有双方的数据，并核对时期、单位、分类口径和样本范围。册数、作品数、访问量、销量、收入和利润不能混用；只有一边的统计，不能据此证明另一边更少。描述一个人的反馈时，也不能悄悄扩大成整个群体的习惯。

- 把事情发生的先后与原因分开。封面排版趋同可以直接描述，“因为经费不足”则需要另有依据；账号关闭不等于公司倒闭，长期没有新作也不自动等于品牌正式停办。没有依据的原因不要用“可能就是”塞进主线。

- 对争议，讲清争的具体内容、触发经过、相关人的说法和后续。不要只写“引发争议”“招来批判”。比较文本、画面或制度时，给足以解释问题的例子，不用一个很普通的相似点支撑严重指控。

- 引述要忠于原话和上下文。采访的时间、受访者身份以及能否区分多人发言都要弄清，不能把几个人的话拼成一个人的完整观点。用户亲自做的采访可以用“我”；别人的采访或检索所得不能冒充自己的经历。

- 区分已经确认的事实、当事人自述、读者评价和推测。读者从小说情节猜作者的私人经历，仍然只是读者的猜测；不能通过省略出处、暗示或打趣，把它写成已发生的现实事件。

- 涉及国籍、性别、政治或其他容易脱离上下文误读的内容，把主体和范围写在句子里。谁说的话、哪部作品的设定、哪批人的行为，要明确指向。选取这类案例也应有解释本期问题的作用，不为猎奇收集普通骂战，再用空泛免责声明收尾。

- 作品介绍不自动等于推荐。平实交代设定和剧情，不把普通桥段写成突破或创新。批评可以直接，但分量要与材料相称：一般、粗糙和明显失误是不同程度，不照抄宣传文案，也不为了显得犀利而夸大。

- 篇幅由有效内容决定。值得讲的过程可以展开，不平均分配每个作品的篇幅，也不为凑时长塞常识和感慨。材料撑不起整期时，收窄范围或说明选题不足，不把邻近但不符合主题的内容硬算进去。

- 标题由实际材料支撑，不先套“兴衰史”“往事”或“从某某到某某”。行业仍在发展，就不要为了标题预设它已经衰亡。用户已经选定的标题、系列名和篇章安排，修改时保留。

- 引入从受众能接住的经验、对象或现象出发，给陌生主题一点铺垫。不要一开口就报一串陌生作品、默认人人听过某首小众歌曲，或先宣布一个尚未介绍的行业已经衰落。

- 开头交代对象和切入点即可，不用长排比提前复述整期的起落、争议和结局，也不机械罗列“这期先讲什么、再讲什么”。默认用自然陈述推进，少靠连续设问、故弄悬念或无必要的往期回顾撑起引言。

- 全文需要一条能顺着听下来的主线。作品、人物和事件各自承担解释作用，不写成“还有一本、还有一个平台”的名单。安排一段时，应能说清它为什么接在这里，以及它给后面的内容提供了什么背景。

- 时间顺序服务于理解，不必拘泥到每句都按年份排。可以集中解释题材、译名或经营方式，但进入支线与返回主线时要交代对象和时期，避免让观众误以为不同年代的事情同时发生。

- 大章节应覆盖相应阶段或主题，不能把单部作品的遭遇、单家公司的调整放大成整个行业的转向。章节卡放在完整段落之间，不插在尚未说完的话中；引言不必强行顶着第一章标题。

- 公司、品牌、平台、出版社、发行商等首次出现时，补上与当前内容有关的身份。讲它们的关系时，用具体例子落地，例如说清哪家公司经营哪个品牌、该品牌出版过什么；不要只抽象地讲“旗下可以有多个品牌”。

- 作品首次出现，先给完整名称或已经确认的称呼，再交代与本段有关的基本情况。介绍故事要说清人物的处境、目标和冲突，不能只报“王国、宗教、成长”之类宽泛关键词，也不要照译一大段无助于理解的环境描写。

- 介绍作者履历、出版经历或海外改编时，把实际阶段分开讲，避免一句“后来”把不同性质的事情全装进去。挑几部代表作不等于作者只写过这几部；说“尝试过动画化”也不能替代重要项目的发起、制作、争议和停摆经过。

- 过渡要有事实关系：前一事件的后续、同一人的下一步、经营方式的变化，或能说明问题的对照。缺的是背景或逻辑时，补背景或调整段落，不靠多加“不过”“于是”“另一方面”掩盖跳跃。

- 检查连接词是否成立。“另一个”前面要有同类的第一个，“因此”前面要有能支持结果的原因，“仍然”要有延续，“却”要有转折。没有这种关系就删掉，不把连接词当口语装饰。

- 代词和省略的主语必须指得清楚。跨过另一部作品、一次类比或一段背景后，再说“它”“这本”“男主”往往已经含混，应重新点明对象。“两个词”“这种变化”“这一套”也不能让观众猜指哪几个。

- 按正常中文的重心安排语序，优先让具体的人或机构做具体的事。比如“文库版的读者一直没等到下一卷”，比“不过一直等不到后续的，是文库版读者”自然。修改病句要重写句法，不能只靠增加逗号和朗读停顿。

- 少用抽象名词和空泛动词代替事实。“小说先在网上连载，后来出了纸书”已经够清楚，就不要改成“纸书从故事的第一次公开变成后续商品”；“作者和读者在这里产生连接”也应换成他们实际做了什么。

- 使用受众熟悉的日常或圈内说法，不为显得专业把普通表达强行学术化。口语化也不等于堆“其实”“还真”“说起来”，更不等于故意写得含混、装熟或编造个人回忆。

- 少用“你会发现”“想必大家知道”“看着就想吐槽”等预设受众反应的句子。直接讲值得注意或值得吐槽的事情。不要在正文和画面里把受众称作“中国观众”，也不摆出教训读者该如何判断的姿态。

- 不替观众提出没人说过的误解，再花一句话否定。已经准确叫作宣传片，就没必要补“不能据此认为电视动画播出过”；刚介绍一个陌生市场，也不必提醒观众“不能只记住争议作品”。确实容易混淆的地方，优先直接把关系讲清。

- 删掉不增加事实或解释的总结、排比和对照。例如“试过的办法不少”“这说明创作者仍在探索”“两者并不是完全一致的方向”，都要检查是否有具体内容。观众能从例子自己看出的普通结论，不必再代为宣布。

- 不把检索过程、审稿判断和自我订正写进口播。“书目能直接核实的是”“有明确的翻译进度”“几个可核对的案例”通常直接改成事情本身。来源身份确实有意义时，自然说明是谁在何时说了什么，而不是展示自己如何查资料。

- 例子用来解决理解难点或支撑判断。介绍陌生收费方式，给一个清楚的实际或明确标为假设的例子；介绍抄袭争议，展示争议中的具体相似处。不要在简单算术后，再替不同类型的读者反复分析常识性的利弊。

- 类比先说明相近之处，再保留影响理解的差别。已有中文概念能帮助理解外语术语时，可以借用；但不要把词的字面直译、当地实际用法和中文近似类型混为一谈，也不要因为几个常见元素相同就推断存在直接模仿。

- 讲词源或翻译差异，把原词、构成、中文意思和具体用例摆出来。观众不懂那门语言时，要解释到能跟上；不能只说“称呼会随关系变化”“语气不同”，却不展示谁对谁说时会怎样表达。

- 讲翻译错误或翻译腔，给原文、实际译法、较自然的表达，再指出字义、语序、指代或语气的问题。例子本身若两种译法都成立，就换一个能说明差别的例子，不勉强判错。大段原文只选与论点有关的部分，并给中文译文。

- 译名史要区分首见记录、当时并存的叫法、后来传播较广的用法，以及今天不同圈子的习惯。不能把几个年代的零散例子编成整齐的接替顺序。音译、意译、借道第三种语言的转译也要分别核实，不能看见相似拼写就认定来源相同。

- 多语言比较可以简讲常见的共同做法，重点展开真正不同的译法，但调研范围不能因此只剩几个方便找到的例子。说“大多数语言如此”之前，要有相应材料；仍有不同使用群体时，把差别讲清，而不是宣布一种叫法彻底统一了全部语境。

- 名称先查官方写法、作者自定译名、封面、版权页及既有中文用法。警惕多音字、同形字、旧字形、谐音和双关；字形相同不保证读法与意义相同，同音也不自动意味着作者有意玩文字游戏。没有依据时，不擅自给人名或笔名配汉字。

- 译名、简称和术语在全文及同系列中保持一致；用户确认的名称优先。首次出现时给必要的全称，后面可以用已经建立对应关系的简称，但不能为了排版擅自缩短用户不接受的书名。纯汉字正文默认用简体，原件截图和有特殊字形意义的讨论保留原貌。

- 外来词的讲法根据用途决定。普通汉字词可以用中文对应词并解释当地含义；纯粹重复英文音译的本地拼写，若不增加信息就不必专门介绍。没有贴切中文译法的术语，可以先解释，再沿用原词，不强造一个含混的新中文标签。

- 发音依据实际语言和用户确认的读法，不把拉丁字母一律念成英语，也不为难念而避开本来该介绍的原文。人名、笔名、作品名和术语分别核对；混合语言时，完整词组不能被不自然的停顿拆散。

- 口播正文、发音输入和字幕显示可以不同。正文与字幕保留正确字形；年份、多音字、连音提示或合成模型需要的替代写法，只用于发音输入。修正发音不等于修改原词，更不应把提示拼写、谐音字或多读出的音节带进字幕。

- 数字以自然、明确、便于阅读为准。日期和精确数据通常写阿拉伯数字，“几千年”之类概数不要机械变成“几1000年”。中文大数字优先考虑万、亿，避免无必要的英文式三位分隔；陌生货币有必要时给带“约”的人民币换算，并核对汇率时期。

- 字幕按语义断句，适合手机观看。避免标点落在行首，避免拆散专名、数量与单位、紧密修饰语。每条字幕末尾可省去句号、逗号等停顿标点，书名号、引号、外语变音符号及有意义的词内标点仍需保留；不要只跟着合成语音的停顿换行。

- 写到外语词、标签或转换结果，画面要给完整对应。讲“傲娇师妹”就不能只显示“傲娇”的外语；讲几个并列标签，就不要漏掉其中几个的原词。长句放不下可以拆页，不能只留受众看不懂的外文，也不用添加“下方为意译”之类多余提示。

- 画面说明应对应当下这句讲解的作品、语言、媒介和版本。比较同一卷的不同版本，就不要混进另一卷；介绍游戏不能配成广播剧封面。并列信息用并列排法，不为了模板硬做成主标题与小字副标题；每页也不必都有标题或装饰性英文。

- 资料出处、发音备注和剪辑说明放在工作信息里，不混入口播与片内文字。系列名、制作版本、“补充资料”“重新整理”等文字，只有确实需要向观众说明时才出现，不默认做成画面内容。

- 结尾接住已经讲完的主线，可以有一两句与事实分量相称的感慨，不突然拔高，也不再报一遍具体作品名单。不要自动追加“好了，这期就聊到这里”、下期预告或征集观众经历；征集的经历也得是目标受众实际可能拥有的。

- 修改时以最新确认稿为基准。用户只改一个措辞，就做相应修改并检查邻接句，不借机重写开头、结尾或替换已经认可的表达。某种说法在一处不合适，不等于以后所有语境都要禁用。

- 用户指出的是一类问题时，检查全文同类问题，而不是只修举出的那一句。多项反馈逐项处理，待查的留住并继续追；不要因为某一项容易做，就把其余要求悄悄丢掉。局部保留原则与全篇同类自查要同时做到。

- 删除、移动或重写一段后，把前后段落连起来读，重新检查主语、代词、时间、连接词和尚未介绍的名词。逐句顺口不等于整篇连贯；应从未看过调研材料的观众角度，完整读一遍。

- 每段都检查它新增了什么事实、解释或必要连接。若删掉后理解完全不受影响，通常可以删掉；若只有一句“这很重要”，则需要的是具体经过而不是更多形容词。不要用相同意思的总结在开头、段尾和结尾反复占位。

- 已确认的文案和读音应保留，不因为重排画面或更换例子就全部重新生成。若任务包含修改成片，台词变化后同步检查对应语音、字幕和切镜；只改了文字就不要宣称视频已经改完。交付指向实际完成的当前版本，不把计划、旧文件或试听当作最终成片。
