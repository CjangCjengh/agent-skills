# 翻译

- 尽量让原文的意思和结构在译文中都有对应，同时符合目标语言的语言习惯和说话逻辑。译入中文时，善用中文的简洁之美；不能只求字面齐全而写出翻译腔，也不能借自然流畅之名改写原作。

- 用户提供的双语示例用于把握措辞、句法、语气和翻译取舍。以用户确认过的译法为准，从多处用例归纳习惯；不要把某个笔误、错译或只适合一处的处理当成文风，也不要把某部武侠小说的语气套到所有作品上。

- 简洁首先来自准确的词和紧凑的句法。中文能够自然省去的重复主语、代词和虚词可以省去，能用一个贴切的动词说清的动作不必绕成一串抽象名词；省下的是冗余表达，不能连动作、意象、程度和人物关系一起省掉。

- 保留原文的信息次序、段落作用和叙述推进。句内语序可以按目标语言调整，长句确有需要时可以拆开，但不要随意把后面的解释提前、把铺垫和落点合并，或将几段话概括成一句结论。

- 看清谁对谁做了什么，以及否定、条件、比较、范围、时间和程度分别修饰哪里。推测不能译成断言，可能发生不能译成已经发生，“看破”不能顺手变成“破解”。中文再顺，也不能掩盖主客倒置或语义增减。

- 连接词承担实际的逻辑关系。原文中的因果、转折、让步和递进要在中文里接得上，不要逐句译对却把上下句译散；也不能为了衔接顺口，给原本只有先后关系的两件事加上因果。

- 原文用词的变化也要尽量保留，尤其是相邻或相互呼应的表达，不把不同的近义词机械译成同词重复。例如 `그래도 하지만……` 译作“可是，但是……”，不译作“可是，可是……”。区分须符合原意和中文习惯，不为换词硬造语义差别。

- 用词可以凝练、有文采，但分寸取决于原文和场景。武侠叙述中贴切的成语、对偶和少量文言表达可以保留；不为显得典雅堆砌生僻词、四字格或原文没有的意象，也不把平实叙述润色成抒情散文。

- 叙述、对白和内心独白可以有不同的口吻。人物说话要像这个人在当前关系和情境下会说的话，保留年龄、身份、亲疏、傲慢、拘谨或随便的区别。口语可以简短、带语气词，不必为求书面整齐把所有人都译得文绉绉。

- 敬语和称谓按人物关系及当下语气处理，不机械地把所有敬语都换成“您”，也不把不同分寸的称呼统一成一个词。同一人物被叫作“老爷子”和“老头子”，可能正体现说话者态度的差别。

- 粗口、讥讽、暧昧和幽默保留原有的意思与力度，不擅自净化，也不额外加重。笑点尽量通过对白、动作和叙述节奏成立，不在译文里解释哪里好笑，不用原文没有的流行梗替换人物自己的表达。

- 保留叙述视角和人物的知情程度。人物的猜测、自嘲、误解和内心反问，不能改成全知叙述者确认的事实；原文的留白和含蓄表达不必补成明说，尚未揭晓的信息不要为了让这一句更好懂就提前说破。

- 原文有意的重复、排比、停顿和短句也是表达的一部分。中文通常可以更短，但不能把强调当赘述删掉，把迟疑补成完整解释，或把刻意留下的半句话一律补成完整句。

- 口吃、结巴和拉长音要逐组核对重复次数与停顿位置，计数包含完整词语开头对应的音节，不任意增减重复、移动停顿或在连续重复中插入顿号。例如 `오, 오오오오오오 오라버니` 中共有八个 `오`，译作 `兄、兄兄兄兄兄兄兄长`；`보보보보, 보통은` 译作 `一一一一、一般`。

- 汉字词已有明确汉字，且照用不太违和、与原意差别不大时，优先沿用。不要仅因词语少见或现代中文不常用，就换成常见近义词；同时核对实际词义，不能把字形相同但含义不同的词机械照搬。

- 人名、地名、门派名、物品名、招式名等，先查原文已有的汉字标注和作者在其他位置给出的写法。已有明确依据时，不因为另一组汉字更顺眼、更像某类名称，就自行换字；没有明示汉字时，也不能把按读音猜出的写法说成作者原定用字。

- 拿不准的汉字专名，要留意后文是否涉及字义、谐音、拆字或伏笔。可以参考用户提供的原版全书、后续卷及其他相关版本，但须核对是否确为同一名称、同一设定。某个词能从原版得到证据，不等于所有改编版译名都可照原版替换；一时没查到，也不等于原版毫无参考价值。

- 专名和固定术语保持一致，已经确认的译法应沿用。统一前先看原词和所指是否相同：同一组织的不同简称可以统一，原文确有区别的两个词不能因为读音相近或旧译相同就合并。普通词仍按语境翻译，不必为表面一致强行一词一译。

- 对含义未明的词，不擅自补出更具体的菜名、材料、招式原理或世界观设定。能够确认到哪一层，就译到哪一层；会影响人物身份、情节理解或全书用词而又无法确定的地方，向用户询问。暂定译法与考证结论要分清。

- 原文疑似笔误时，先核对原件、上下文及可用版本。上下文足以明确排除字面解释时，可以在译文中按明确含义修正，另记原文疑点；仅仅觉得奇怪、不合常识或不够顺，不能当作擅改依据。双语数据中的原文仍保留原样，除非用户另有要求。

- 典故、成语和文化用语要译出当前文本实际使用的意思。现成的中文表达贴切时可以用，但不能借用一个成语而多带进原文没有的评价。作者对典故的改写可能服务于剧情，不要因为知道经典原句，就把小说中的讲法强行校回经典。

- 除下面的中文引号与方括号约定外，尽量沿用原文的标点种类、位置和停顿，不为追求顺口而任意改逗号、句号、问号或省略号。标点字形可以按目标语言规范调整，保留其区分对白、内心独白、引用和打断等作用。

- 译入中文时，原文的单引号统一用『』，双引号统一用「」，不因心理活动、脑内对话、回忆对白或正文引用另作区分；原文的 `[]` 改为全角［］，普通括注仍用（）。其他不确定的标点处理向用户确认。

- 标点保留以语言习惯和实际句意为限。中文省略号后不再加句号，可按语气保留问号或感叹号。日韩语中有些实际问句以句号结尾，译入中文时可按句意改用问号；泰语等原文少用或不使用标点的情形，应按语法、语义和语气补出目标语言所需的标点。不要把原文缺少标点等同于全段只有一句话。

- 拟声词、叹词和笑声按实际声音及语气选择目标语言中自然的写法，兼顾长短、重复和强弱。不能只照字面音译，也不要将独立的声响一律改成“他笑了”“发出响声”之类叙述。

- 数字、时长、次数和单位逐项对照，结合场景判断多义词。例如武侠交手中的“招”不能误作计时的“秒”。遇到前后数字矛盾，要查清能否确定是哪处出错，不能为了凑得上就任改一个数。

- 保留有意义的段落、空行、标题及强调格式。加粗、斜体或着重标记要落在译文对应的词义上，不按原文字符位置机械套用；同类格式跨段、跨页保持一致。来自扫图或排版文本时，区分真正分段与页面宽度造成的折行。

- 连续作品要结合前后文翻译，留意跨段指代、前文铺垫和后文照应。按页或按批处理时，仍要延续已经确认的专名、人物口吻和格式，不能每换一页就重新作一套选择。

- 审校用户已有译文时，先修漏译、错译、误字和影响理解的表达，再考虑同一风格下确有改善的措辞。不要只因个人更习惯另一种说法，就把原本准确、自然且有特色的句子全面重写。用户指出一类问题时，检查其他同类位置。

- 修订后既对照原文检查信息是否完整，也把相邻译文连起来读，检查主语、指代、逻辑、口吻和节奏。单句顺口不等于整段成立；自然度检查发现的问题，应回到原文确认，不能只凭中文顺不顺继续改意。

- 交付的译文应能独立阅读。除用户要求或原文本来就有的内容外，不擅加译者说明、来源页码和考证过程；需要保留的疑点与修订说明另放。双语 JSON 沿用用户指定的字段和条目对应关系，不把说明混入原文或译文字段。
